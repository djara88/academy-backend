# 05 — Manual de Usuarios de Syncademia

## 1. Introducción

Syncademia es una plataforma SaaS para academias deportivas. Permite gestionar estructura, deportistas, profesores, matrículas, cobros, asistencias, comunicaciones, competencia y rendimiento desde un solo entorno.

Este manual cubre tres perfiles principales:
- Director/Administrador de academia;
- Profesor;
- Apoderado mediante Apoderados PRO.

## 2. Director / Administrador

### Primer ingreso
1. Iniciar sesión con la cuenta de dirección.
2. Revisar el Dashboard.
3. Completar la puesta en marcha.
4. Configurar sede y rama deportiva.
5. Crear categorías.
6. Registrar profesores.
7. Iniciar matrículas/importación.

### Estructura de academia
Ruta sugerida: **Configuración → Estructura**.

Jerarquía:
`Academia → Sede → Rama deportiva → Categoría`

Ejemplo:
- Academia Titanes;
- Sede Providencia;
- Básquetbol;
- U15.

Una misma academia puede disponer de varias sedes y disciplinas según plan contratado.

### Matrícula
El Director puede registrar un deportista nuevo con sus datos, apoderado, sede, rama, categoría, matrícula y mensualidad.

Un deportista ya existente puede inscribirse en otra disciplina sin duplicar su ficha personal. Cada inscripción deportiva conserva su propia sede, rama, categoría y situación financiera.

### Finanzas
Funciones habituales:
- cuenta corriente por deportista;
- matrícula;
- mensualidades;
- cobros y pagos;
- morosidad;
- ingresos/egresos;
- reportes y conciliación operativa.

Buenas prácticas:
- registrar pagos desde el flujo correspondiente;
- no crear manualmente duplicados para corregir diferencias;
- validar siempre alumno, concepto y periodo.

### Asistencia
El Director puede consultar asistencia global y alertas. Las asistencias registradas por profesores alimentan el historial del deportista.

### Evaluaciones
Formación utiliza criterios estándar por disciplina.

Competencia y Alto Rendimiento pueden habilitar criterios personalizados por rama. Cuando se cambia una metodología, Syncademia versiona el perfil para evitar comparar evaluaciones incompatibles.

### Partidos y torneos
Los encuentros se vinculan a categoría/rama. Las estadísticas competitivas se adaptan al deporte cuando existe perfil específico.

### Apoderados PRO
Es un complemento de pago por academia.

Cuando está activo:
- las familias acceden a su portal;
- consultan información vinculada a sus hijos;
- disponen de comunicaciones habilitadas;
- pueden solicitar una inscripción en otra disciplina.

La solicitud de una nueva disciplina no genera cobros automáticamente: Dirección debe revisar categoría, matrícula, abono y mensualidad y luego aprobar.

## 3. Profesor

El profesor opera únicamente sobre el alcance habilitado para su rol.

Funciones típicas:
- categorías asignadas;
- listado de deportistas;
- toma de asistencia;
- información necesaria para entrenamiento/competencia;
- evaluaciones cuando el plan/rol lo permita;
- seguimiento deportivo.

El profesor no debe disponer de funciones administrativas globales de facturación o configuración de academia salvo autorización explícita.

### Toma de asistencia
1. Seleccionar categoría/entrenamiento.
2. Marcar presentes/ausentes.
3. Guardar.
4. Verificar confirmación.

Evitar mantener listas paralelas fuera de Syncademia salvo contingencia temporal.

## 4. Apoderado — Apoderados PRO

### Acceso
El portal se encuentra disponible cuando la academia tiene licencia Apoderados PRO vigente o se encuentra en trial Full.

### Información disponible
Según configuración y permisos:
- hijos/deportistas vinculados;
- disciplinas/inscripciones;
- estado de cuenta;
- comunicaciones;
- citaciones;
- documentos;
- solicitudes disponibles.

### Solicitar otra disciplina
1. Seleccionar hijo.
2. Elegir sede y disciplina disponible.
3. Indicar categoría preferida si corresponde.
4. Agregar comentario opcional.
5. Enviar solicitud.

La solicitud queda pendiente de Dirección. No constituye aceptación automática ni crea deuda hasta la aprobación.

## 5. Privacidad y seguridad para usuarios

- no compartir contraseñas;
- cerrar sesión en equipos compartidos;
- reportar accesos sospechosos;
- no copiar información de menores a grupos o sistemas externos sin necesidad;
- usar canales oficiales para rectificación/eliminación;
- ante error de datos, contactar a la academia.

## 6. Problemas comunes

### No puedo iniciar sesión
- verificar correo;
- revisar contraseña;
- usar recuperación/canal de soporte;
- confirmar que la cuenta esté activa.

### No veo una función
Puede depender de:
- rol;
- plan;
- licencia Apoderados PRO;
- sede/rama asignada;
- estado de la cuenta.

### Veo información incorrecta
No crear un segundo alumno como solución. Solicitar corrección a Dirección para preservar historial y cuentas.
